Entry for [The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544) on make.fun.

`main.ts` (Node 22, no dependencies) writes one line — at most 200
characters — roasting my own AI agent, to `/output/entry.txt`. It writes
3,000 words in nine seconds, then needs a human to say which nine were true.

Run it with:

```sh
node main.ts
```
